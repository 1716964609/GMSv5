# GMS v5 — Product Vision

**文書バージョン：** Baseline 1.0  
**開発方法論：** AI Unified Process（AIUP）  
**文書状態：** Product Owner決定反映済み・仕様ベースライン

## 1. 目的と提供価値

GMS v5は、ユーザー自身が管理する専門用語集を使って、多言語文書を安全かつ一貫して翻訳するためのWebアプリケーションである。用語の登録・検索・再利用と、DeepLによる一次翻訳、OpenAIによるポストエディティングを一つの流れにまとめ、専門用語を含む翻訳の品質管理を支援する。

## 2. 想定ユーザー

自分の用語資産を持つ個人ユーザーを対象とする。ユーザーはメールアドレスでアカウントを管理し、自分のGlossaryとTermだけを操作する。一般ユーザー間の共有・管理者ロールは本仕様の対象外である。

## 3. 基本方針

- **Bring Your Own Glossary：** ユーザーがGlossaryを作成し、Termを手動またはJSONで管理する。一つのTermは一つの原語表現と一つの訳語表現のペアである。
- **Bring Your Own API Key：** ユーザー自身のDeepLおよびOpenAI APIキーを登録して使用する。キーはユーザー単位で分離し、画面やログへ平文を返さない。
- **用語管理と翻訳：** 同一Glossary内の重複は4属性完全一致で判定し、異訳語は共存できる。翻訳時に候補が衝突した場合は、リクエスト単位でユーザーが一つを選ぶまで外部APIを呼び出さない。
- **多段階翻訳：** DeepLを一次翻訳、OpenAIをポストエディティングに使用し、最終訳文だけを成功結果として返す。
- **データ所有権の分離：** Glossary、Term、プロフィール、API認証情報へのアクセスは所有ユーザーに限定する。
- **プライバシー：** 原文、DeepL中間訳、最終訳文は業務データベースへ永続化しない。外部送信はユーザーの明示同意を必要とする。

## 4. 対象範囲

公開ランディングページ、メール確認付き登録、ログイン・ログアウト、パスワードリセット、Glossary／TermのCRUD、JSONインポート、用語検索、APIキー管理、用語選択付き翻訳、TXTダウンロード、プロフィール変更、アカウント削除後の内部保持と恒久削除を対象とする。デスクトップでは5カラムのGlossary管理画面を維持し、狭い画面では5機能すべてにアクセスできるパネル切り替え方式を採用する。

## 5. 対象外・後続設計

アカウント削除後のユーザー向け復旧、Glossaryの共有、管理者ロール、翻訳履歴の永続化、外部API制限を回避する自動分割・自動省略は提供しない。認証プロバイダー、ORM、データベース、クラウド、暗号化・鍵管理の具体製品、詳細なモバイル寸法および候補選択UIは後続のArchitecture／UI設計で決定する。
